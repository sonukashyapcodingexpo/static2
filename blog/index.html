What a first release should leave out

The features that make a first version feel complete are often the ones that keep it from shipping.

A first release is the smallest system that lets a real user finish a real job. The left-out list is part of the plan.

Handover is a product

A repository without a walkthrough is a locked drawer. We treat the handover as part of the build.

Accounts, a runbook, and an hour with the people who will own the system. The zip file is the least of it.

Support is not a leftover

The week after launch is when staff find the real edge cases. Plan for that week on purpose.

The support window is scheduled with the same team, so the first real month is not an afterthought.
